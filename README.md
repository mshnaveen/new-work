# Git Branch Contributors Utility

## Overview

This utility helps identify contributors to a specific Git branch by retrieving and displaying the unique authors who have committed changes to that branch.

## Purpose

The script is useful for:

* Tracking branch contributors
* Reviewing team participation
* Identifying commit authors for audits or reporting
* Understanding contribution history within a branch

## How It Works

The utility analyzes the commit history of a selected Git branch and extracts the author information from each commit. It then presents a deduplicated list of contributors, making it easy to see who has worked on the branch.

## Use Cases

* Development teams managing multiple contributors
* Project maintainers reviewing branch activity
* Release managers validating contribution records
* Repository administrators generating contributor reports

## Usage Notes

Run the utility from within a Git repository and specify the target branch. The output will display the contributors associated with that branch.
